Grading notes (scenarios referenced by topic, not row number — rows renumber when scenarios are inserted): state the task plainly to the subagent; a first 2026-09-14 run that labelled each task "Scenario N" sent four haiku spawns looking for a numbered scenario inside the skill file, which they reported absent, so that run was discarded and re-run. The two model-availability scenarios (fable excluded, only sonnet) test that a missing fable leaves the gate on opus and that a lone sonnet takes the gate; the orchestrator-model scenario tests that the session's own model does not set the gate's tier; the inherit-anyway scenario tests the explicit-over-inherited rule, not tier choice; the two effort-surface scenarios test passing per-call effort where the Agent schema takes it and routing through a workflow or a pinned agent type where it does not; the fix-reverification scenario tests the named-checklist-is-not-a-gate rule, drawn from a real mis-tiering on 2026-08-12 (a fable re-gate corrected to sonnet); the lens scenario tests that a fanned-out gate is lens review whatever its label, drawn from the fanned-out gate-type call sites in the 2026-10-08 research record; the Haiku 4.5 scenario tests that effort is passed even where the model has no setting for it; the escalation scenario tests the one route to fable; the fork scenario tests that forking chooses the session's tier.
